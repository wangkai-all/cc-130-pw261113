# 现金计划 · CashPlan

13 周滚动现金预测：导入应收应付、已收付款与期初余额，按周展示预计流入、流出与最低余额，点进任意一周可下钻到每张单据的剩余未结金额与预计结算日。

无外部运行时依赖，使用 Node.js 内置 `node:sqlite`、`node:http`，前端为原生 ES Module 单页应用。

## 启动

```bash
npm start          # http://localhost:3000
npm test           # 64 个领域 / 集成测试
```

首次启动会自动建库并写入演示样本（含部分到账、逾期未付、跨假期、多币种缺汇率、未分配收付款）。设置页可一键重置。

环境变量：`PORT`（默认 3000）、`DB_PATH` / `DATA_DIR`（默认 `./data/cashflow.db`）。

## 核心行为

**预测口径**
- 只计入单据**未核销余额**（`amount_original − 有效核销合计`），已核销部分不重复计入。
- 账面到期日 `due_date` 用于逾期判断；预计结算日 `expected_date` 用于排期，两者独立。
- 结算日按工作日历顺延：周末规则 `next / prev / nearest / none`，导入假日始终视为非工作日。原始日期与顺延天数在明细中分别列出。设置页切换日历会保存为默认日历，预测立即按新日历重算。
- 多币种按**本次方案汇率**（单据显式汇率 → 方案汇率）折算；缺汇率项目不进入合计，单列在「缺汇率项目」面板，不会以 0 金额混入预测。缺汇率面板列示的是仍未结/未分配的金额，已核销部分不会重复计入；计划起始日之前发生的缺汇率收付款也会单列，避免其现金在期初余额中被悄悄漏算。导入时未填汇率的行保持空汇率，继续跟随方案汇率，之后在设置里调整汇率会自动生效。
- 期初余额按币种取快照：同一币种存在多个余额日期时，只计入计划起始日前后最近的一次，避免重复累加。

**核销**
- 一张单据可多次部分核销；一笔收付款可分摊到多张单据。
- 每次核销校验：币种一致、方向一致（收款→应收、付款→应付）、金额 > 0、不超过收付款可用余额与单据未结金额。
- 撤销核销立即恢复双方未结/可用余额；恢复已撤销核销时重新校验余额，余额已被占用则拒绝恢复。
- 导入按业务键去重（类型+单号+单位+币种+金额+到期日），重复导入跳过、不重复冲减。币种计入键，避免不同币种的同号单据被误判为重复。

**情景**
- 情景只保存客户级延迟天数与单据级日期覆盖，写入 `scenario_overrides` / `scenario_customer_delays`，**从不改写原始单据**。写入前先整体校验再在单个事务中落库，某一行的客户/单据不存在时整次保存失败，原有假设不会被部分覆盖。
- 对照视图并排列出各情景的最低余额、缺口、缺口周数，与基准的差额；顶部「查看」切换预测所用情景。

**可核对**
- 所有 KPI 与周汇总均可点击下钻；周明细列出每张单据的原币未结、折算金额、顺延/情景标记、预计结算日。期初余额下钻列出每个币种的原币金额、汇率来源（本位币 / 单据汇率 / 方案汇率）与余额日期；流入、流出下钻按单据汇总并列示涉及的每一笔。
- 「设置 → 运行核对」校验：无超核销、周明细之和等于周合计、周合计之和等于总流入/流出。

## 导入格式

CSV、UTF-8、首行表头。支持中英文列名。

单据（应收应付）：

```csv
类型,单据号,往来单位,币种,金额,汇率,开票日期,到期日,预计结算日,备注
应收,AR-1001,华东精密机械有限公司,CNY,286000,,2026-11-01,2026-11-20,2026-11-24,部分到账
应付,AP-2001,宝钢原材料供应有限公司,USD,38000,7.15,2026-11-02,2026-11-25,2026-11-30,
```

- `类型`：`ar` / `应收` / `receivable` 或 `ap` / `应付` / `payable`
- `汇率` 留空时使用方案汇率；方案也没有该币种则单列。
- 缺少 `预计结算日` 时沿用到期日。

收付款：

```csv
类型,单号,往来单位,币种,金额,汇率,收付款日期,备注
收款,RC-3001,华东精密机械有限公司,CNY,120000,,2026-11-10,
付款,PM-4001,宝钢原材料供应有限公司,CNY,90000,,2026-11-11,
```

期初余额：

```csv
币种,金额,余额日期
CNY,1250000,2026-11-14
```

导入页可下载对应模板或加载示例内容。

## 结构

```
server/
  db.mjs        schema / settings / SQLite 连接
  domain.mjs    纯函数：日期与日历规则、汇率、CSV 解析、核销校验、预测装配
  repo.mjs      数据访问、导入、情景、预测输入
  seed.mjs      演示数据
  index.mjs     HTTP API + 静态服务
public/
  index.html    单页应用
  styles.css    浅色/深色主题
  js/chart.js   周度流入流出柱 + 余额折线（双面板共用时间轴）
  js/*.js       视图模块
tests/
  domain.test.mjs  30 个纯函数测试
  repo.test.mjs    18 个数据库/导入/核销集成测试
```

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/bootstrap` | 设置、日历、客户、情景 |
| GET | `/api/forecast?scenario=N` | 周度预测（N=0 为基准） |
| GET | `/api/documents?kind=&q=` | 单据及已核销/未结 |
| GET | `/api/documents/:id` | 单据 + 核销记录 |
| GET | `/api/payments?kind=&unapplied=1` | 收付款及可用余额 |
| POST | `/api/allocations` | 新增核销 |
| POST | `/api/allocations/:id/void` | 撤销核销 |
| POST | `/api/allocations/:id/restore` | 恢复核销 |
| GET/POST/PATCH/DELETE | `/api/scenarios` | 情景 CRUD |
| POST | `/api/import` | CSV 导入（documents / payments / opening） |
| GET | `/api/audit` | 一致性与超额核销核对 |
